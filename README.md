# 二次元摄影约单工具（框架版）

这是一个零依赖的 Node.js 原型框架，包含手机预约页、管理后台、表单模板、时间段模板和支付状态模拟。

## 项目结构

```
booking-app/
├── server.js          # 主服务（零依赖，Node.js 内置模块）
├── public/            # 前端页面（原生 HTML/CSS/JS）
│   ├── index.html     # 登录/注册页
│   ├── booking.js     # 客妹接单页
│   ├── admin.html     # 管理后台
│   └── admin.js
├── data/store.json    # 运行时数据（首次启动自动生成，不入库）
└── public/uploads/    # 参考图上传目录（不入库）
```

`data/store.json` 会在首次启动时自动生成（含演示账号），无需手动准备；删除该文件即可重置数据。

## 启动

```bash
node server.js
```

打开：

- 初始页面（登录/注册）：http://localhost:3000/
- 客妹接单页：http://localhost:3000/p/{摄影师ID}
- 演示账号：`demo` / `admin123`

## 当前能力

- 客妹选择日期和时间段，填写模板表单并提交预约
- 支持联系方式（QQ/微信）、多选必填、参考图上传
- 支持“备注”展示型题目和“选择后显示后续题目”的条件逻辑
- 摄影师注册后获得专属 ID，后台数据按摄影师隔离
- 时间模板支持设置开始/结束时间和间隔（默认 20 分钟），自动生成时段
- 表单模板和时间段模板可保存、复用
- 定金/尾款金额进入订单，已接入爱发电收款：客妹跳转爱发电方案页支付，Webhook + 轮询自动确认到账；摄影师未配置时自动降级为模拟支付
- 预约状态、支付状态可在管理后台修改（含手动标记兜底）
- 数据保存在 `data/store.json`；爱发电凭据在 `data/afdian.json`（不入库）

## 支付接入（爱发电）

摄影师在「管理后台 → 爱发电支付」配置自己的爱发电账号：

1. 注册爱发电创作者（免费，无开户费；平台在提现时抽成约 6%），创建「自定义金额」方案，复制方案页链接
2. 爱发电主页右上角 → 开发者页面，获取 `user_id` 和 `token`
3. 开发者后台配置 Webhook 回调 URL（`http://你的域名:3000/api/afdian/webhook`）并填写回调 Token
4. 后台填入凭据并启用，点「手动同步订单」验证连通

客妹点击「去爱发电支付」→ 跳转到方案页（自动携带预约编号和金额）→ 支付后 Webhook 实时回调 / 轮询（默认 5 分钟）自动确认 → 订单状态自动推进；匹配失败的订单进「待核对」人工关联。

- 本地开发：`AFDIAN_MOCK=1 AFDIAN_POLL_MS=1000 node server.js` 跑假支付链路（严禁生产开启）；端到端测试：`node test/afdian-e2e.cjs`
- 签名算法与接口字段以爱发电官方文档为准，集中在 `lib/afdian.js` 的 `sign()`/`normalizeOrder()` 两处
